Fatih Bulut

Security & AI Researcher · Principal Applied Scientist @ Microsoft

I build AI systems that make security operations autonomous. I trained Microsoft's first security-specific language model, SecEncoder, which was purpose-built on security logs, shipped into Defender Experts for XDR, and led to the company's first AI-driven threat actor discovery. I helped prototype Microsoft Security Copilot, shipped the Threat Intelligence Agent in Microsoft Perception to general availability, and now lead autonomous purple teaming, building agentic systems that find detection gaps before attackers do.

At IBM Research, as a Senior Technical Staff Member, I built ML-driven solutions for vulnerability prioritization, compliance policy management, and hybrid cloud security that shipped into X-Force Red and Cloud Pak products, and I represented IBM in the CVSS SIG. I have 48+ patents and 40+ publications, and I teach graduate courses at Columbia University.
